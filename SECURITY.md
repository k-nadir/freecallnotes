# Security

Please report security problems privately, not in a public issue: use GitHub's "Report a vulnerability" button on this repository (Security tab). We'll reply as soon as we can.

Things that are in scope include anything that could expose recordings or transcripts, make the local interface reachable from another computer, or run code from a tampered model download.

FreeCallNotes listens only on 127.0.0.1 and has no accounts or cloud services.
